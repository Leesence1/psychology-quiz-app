# 题库补全规范（content/staging）

本目录是**暂存区**：新题目先写成独立 JSON 片段，**不要直接改 `public/questions.json`**。
合并、查重、校验由主流程统一做（见 `RELEASE.md`）。

## 为什么不能直接抄真题 ⚠️

两条独立风险，任何一条都足以否决：

1. **著作权**：真题题干不适用《著作权法》第五条(一)的官方文件豁免（命题机构是"受委托执行
   公务的单位"，非国家机关），有独创性的题目受保护；**解析/答案明确受保护**。
2. **国家秘密**：《2021 年全国硕士研究生招生工作管理规定》第七条把招生单位**自命题科目试题、
   参考答案、评分参考按教育工作国家秘密范围严格管理**。CC BY-NC-SA 的 NC 条款
   **无法处理保密义务**。

**所以：只复现「考点」（事实、理论、定义、机制），绝不复刻「表达」（题干措辞、选项编排）。
题目必须自己撰写。** 不要写"【2024 真题】"这类来源标注。

## 输出格式

每个片段写到 `content/staging/<chapterId>.json`，内容是一个**章节对象**：

```json
{
  "id": "stat3",
  "title": "统计 第3章 关于总体平均数的推断",
  "questions": [ /* ... */ ]
}
```

### 题目字段

```json
{ "type": "single",       "id": 1, "q": "题干", "options": ["A","B","C","D"], "answer": 2, "explain": "解析" }
{ "type": "multi",        "id": 2, "q": "题干", "options": ["A","B","C","D"], "answer": [0,2], "explain": "解析" }
{ "type": "subjective",   "id": 3, "q": "名词解释：XXX", "answer": "答案要点" }
```

- `type` 只能是 `single` / `multi` / `subjective`
- `answer`：`single` 是**整数索引**（0 起）；`multi` 是**无重复整数索引数组**；`subjective` 是**非空字符串**
- `id` 在**本章内**从 1 连续编号
- 客观题**必须**有 `explain`
- `options` 通常 4 个（A–D）。超过 4 个也可以（UI 支持 A–Z），但要确认是有意的
- 可选字段 `syllabusRef`：考点路径，如 `"心理学统计/第3章/假设检验的基本逻辑"`

## 每章题量与题型配比

每章 **不少于 12 题**，按这个配比（考点覆盖优先于凑数）：

| 题型 | 数量 | 说明 |
|---|---|---|
| `single` 单选 | 6 | 概念辨析、公式适用条件、结果解读 |
| `multi` 多选 | 2 | 并列要点类考点 |
| `subjective` 主观题 | 4 | **至少 1 个名词解释 + 1 个简答 + 1 个论述** |

主观题的 `q` 用中文题型前缀，便于 UI 自动识别：
`名词解释：`、`简答：`、`论述：`、`实验设计：`

## 质量要求（这是重点）

1. **优先高频考点**，不要冷僻细节。判断标准：这个点在教材里是**加粗标题级**的概念、
   或是**常考的辨析/对比**吗？是就写。
2. **每题只考一个考点**，便于错题归因。
3. **干扰项要"像真的"**：用同一体系内易混的概念（如 标准差 vs 标准误、
   信度 vs 效度、α 错误 vs β 错误），不要凑数。
4. **解析必须说清"为什么错"**，而不只是重复正确答案。
5. **统计/测量的重点在"方法选择 + 结果解读 + 适用条件"，不是公式推导。**
6. **绝不出错**。宁可少写一题，也不要写一个你不确定的事实。
   - 数值类（如 7±2、0.05 显著性水平、IQ 常模均值 100 标准差 15）必须准确
   - 人名/理论归属必须准确（如 信号检测论→Tanner & Swets；
     STROOP→Stroop；门控理论→Melzack & Wall）
   - 拿不准就换一个你有把握的考点

## 章节 id 约定（不要用别的）

现有题库的 `ch3`/`ch4`/`ch5`/`ch6` 是**按某本教材目录**编的，**保持不动**（改了会
让用户已保存的答案与错题本失联：localStorage 键是 `quiz_<chId>_<qId>`）。

新章节用**官方范围**命名：

| 板块 | id |
|---|---|
| 统计 第1–7章 | `stat1` … `stat7` |
| 测量 第1–6章 | `meas1` … `meas6` |
| 导论 缺的章 | `guide1` `guide2` `guide3` `guide7` `guide8` `guide10` `guide11` |

（导论 4/5/6 的内容已由现有 `ch4`/`ch5`/`ch6` 覆盖，不要重复出。）

`title` 建议写成 `"统计 第3章 关于总体平均数的推断"` 这样带板块前缀，便于用户识别。
