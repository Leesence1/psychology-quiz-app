## [v2.3.1] - 2026-09-20

### Fixed
- **`stat1` 违反题型配额**：v2.3.0 合并进去的是该章返工中的中间版本（14 题 / **8 单选**，
  而 SPEC 规定 6 单选）。已替换为 12 题 / 6 单选 + 2 多选 + 4 主观。
  删掉的两道单选与保留题重复：①"偏态分布中平均数、中数、众数的关系"
  ②"两名学生跨班比较相对位置"（z 分数考点已在多选中覆盖）
- 题库 404 → 402 题（26 章不变）

### Notes — 流程
本次事故的原因是**就绪门判断错误**：合并前只校验了"20 个片段都能解析"，
没有校验"作者已经收工"，于是在某章返工途中把它吃进了生产题库。
`RELEASE.md` 应补充为：**必须等所有作者 agent 明确回报完成后再合并**，
不能仅凭文件可解析就认为就绪。

## [v2.3.0] - 2026-09-20

### Added — 题库对齐官方 24 章范围：+20 章 / +245 题

此前题库只覆盖官方【心理学导论】的 3 个主题（约 128/159 题压在学习记忆·意识注意·
感觉知觉），而官方范围内 **统计 7 章 + 测量 6 章几乎为零**（分别约 6 题与 2 题）。
本次把骨架补齐到官方三板块：

- **题库 159 → 404 题，6 → 26 章**
- 新增【心理学导论】缺的 7 章：`guide1` 研究对象与学科发展 · `guide2` 心理学研究方法 ·
  `guide3` 生物学基础 · `guide7` 思维 · `guide8` 情绪 · `guide10` 智力 · `guide11` 人格
- 新增【心理学统计】全部 7 章（`stat1`–`stat7`）
- 新增【心理学测量】全部 6 章（`meas1`–`meas6`）
- `guide2` 给到 14 题（6 道主观题，含 2 道「实验设计：」题型）——官方把"基本实验设计"
  放在这一章，而实验设计是单题 50–60 分的大题来源，故刻意加厚
- 每道题带 `syllabusRef` 考点路径（形如 `心理学统计/第5章/平方和与自由度的分解`），
  为后续「官方范围覆盖率」指标打底

### Added — 出题与合并流水线

- `content/staging/SPEC.md`：出题规范，含**版权红线**（只复现考点、绝不复刻真题表达）、
  题型配比、id 约定、质量要求
- `scripts/merge-staging.mjs` + `npm run merge:questions`：片段式并行出题 →
  **单一写入者**合并。幂等（同 id 章节替换而非追加），遇到非法 JSON 或 id 冲突直接退出，
  不会把坏数据写进生产题库

### Fixed
- 修复 `stat1` 章内 id 重复（两题共用 `quiz_stat1_13`，会互相覆盖已保存答案）

### Notes — 内容正确性

新增题目由 AI 按官方考点撰写，**格式已全部机器校验**（id 唯一且连续、答案索引在范围内、
`multi` 无重复且 ≥2 项、主观题答案非空、客观题均有解析），但**事实正确性未经逐题人工复核**。
已发现并留待统一的争议点：吉尔福特 SOI 因素数在不同教材间口径不一
（`guide10` 选择回避数值，`meas3` 写作 5×5×6 = 150），请按自己教材口径统一。
题库中标注「华东师大 347 历年真题」的既有章节，其来源与合规性需单独确认
（自命题试题的著作权与保密风险见 `docs/research-347-*.md`）。

## [v2.2.0] - 2026-09-20

### Added — 主观题练习模式（补上最大的产品缺口）
考试 300 分里 **250 分是主观题**，而此前 `App.tsx` 用
`filter(q => q.type !== 'subjective')` 把主观题完全排除在刷题之外 ——
题库里 45 道主观题**一道都练不到**，`past_exams` 章节 19 题里有 17 题因此不可用。

- 侧边栏新增「主观题背诵」入口，显示未掌握数量徽章
- 每题：题型标签（从题干自动识别名词解释/简答/论述/实验设计/翻译/写作）、
  所属章节、题干 → 点击展开**答案要点**
- 三级自评：不会 / 模糊 / 已掌握（再点一次可撤销误触），存入 localStorage
- 顶部显示「考试 300 分里 250 分是主观题 · 已掌握 N / 45」与进度条
- 章节筛选（全部 / 各章）与「只看未掌握」开关
- 仪表盘统计条新增「主观题掌握」一格

自评数据存在独立键 `quiz_subj_rating`（`${chId}-${qId}` → 1/2/3），
不影响既有的判分与错题本数据。

验证（headless 浏览器实跑）：45 道主观题全部渲染可达、答案可展开、
自评写入成功、「只看未掌握」筛选 45 → 44、**刷新页面后自评保留**。

### Fixed
- 顺带修正 v2.1.1 中新增的校验器警告文案：它仍声称"UI 只支持 A–D"，
  而该问题已在同一版本修复，属于过时信息

## [v2.1.1] - 2026-09-20

### Fixed
- 🐛 **多选题根本无法多选**：`sel()` 只把单个选项写入 state，UI 没有多选逻辑，
  而判分契约要求 `multi` 的答案是**索引数组** —— 因此多选题**永远判错**，
  且提交后正确项也不会高亮（`opt.id === answer` 拿字符串比数组，恒为 false）。
  现改为单选替换、多选切换，按契约分别存索引 / 索引数组，正确项用 `includes` 判断
- 🐛 **超过 4 个选项的题渲染空白徽章**：选项字母硬编码为 `['A','B','C','D'][j]`，
  而题库中 ch6 有两道 6 选项题（含"以上都对/都不对"），第 5、6 个选项的 `id` 为
  `undefined`：徽章空白，且点击会把索引 -1 写入答案。现统一用 `letterAt(i)` 支持 A–Z，
  键盘选择也随实际选项数放开通配
- 多选题类型标签补上「可多选」提示（**不透露**正确项数量，与真实考试一致）

### Added
- `scripts/validate-questions.mjs` 与 `npm run validate:questions`：题库校验器，
  检查 JSON 合法性、章内 id 唯一、`single`/`multi` 答案索引越界、
  `subjective` 缺答案要点等。本批的两个 bug 正是它先报出来的
- `.github/workflows/ci.yml`：push / PR 时自动校验题库并构建，
  补上此前完全缺失的质量门（两个站点都直接从 `main` 构建，之前没有任何拦截）
- `CONTRIBUTING.md`：开发环境、题库贡献规范与**版权边界**、提交信息与分支规范
- `RELEASE.md`：正式化发布流程（版本号判定规则、附注 tag、GitHub Release、双站点验证）
- `AGENTS.md`：给 AI 助手的项目上下文与红线，保证跨会话一致
- README 补充题目更新与校验说明

### Changed
- 移除冗余文件：根目录 `questions.json`（与 `public/questions.json` 逐字节重复且无人引用）、
  `public/index.html`（v1 页面，构建时被 Vite 产物覆盖、从不发布）、
  `src/App-full-code.txt`（已与 `App.tsx` 脱节的陈旧快照）
- README 不再引用未入库的 `legacy/` 路径（`legacy/` 已被 gitignore，外部贡献者看不到）

### Performance
- 移除上述文件后 Tailwind 不再扫描它们，**CSS 由 70.92 KB 降至 40.55 KB**
  （gzip 10.81 → 7.54 KB，约 −43%）

## [v2.1.0] - 2026-09-20

### Fixed — 两个真实 bug
- 🐛 **全站留白失效**：`index.css` 里那条无层级的 `* { margin: 0; padding: 0 }` 优先级高于 Tailwind 的 `@layer utilities`，导致全站 `p-*` / `px-*` / `py-*` / `m-*` / `space-y-*` 全部失效（只有 `gap-*` 幸免）——这才是页面「拥挤」的真正原因。已移除该 reset（Tailwind preflight 已提供 box-sizing 与归零）
- 🐛 **错题本刷新后被清空**：`initialState` 中 `wrongBook` 写死为空数组，且 `QuizProvider` 挂载时的 effect 会立刻把它写回 localStorage，于是每次刷新错题记录都被抹掉（`getWrongBook` 已定义但从未被调用）
- 移除 `wrangler` 的 `assets` 配置，修复 Cloudflare Pages 上的 JS MIME 类型错误
- 补上 Cloudflare Pages 的 SPA 路由配置
- 修复 TypeScript 类型错误

### Changed — 仪表盘重构
- 顶栏：去掉与右上角重复的正确率，修复用户名被裁切溢出，图标按钮补 `aria-label`
- 侧边栏：移动端改为横向滚动胶囊行，桌面端保持竖排 sticky
- 仪表盘：hero 收紧、CTA 垂直居中；4 张统计卡合并为一条 strip + 总进度条
- 章节卡：信息从 4 行压到 2 行，去掉重复的「共 N 题」与冗余「刷题进度」标签
- 进度条轨道调亮，0% 时也能读出「空进度」；0% 不再用彩色强调
- 主题：深蓝底色（`#0c1222`）+ 统一 lucide 图标 + 知识网格背景
- 清理 `index.css` 中 64 行与 Tailwind 默认值完全相同的 `@theme` 调色板副本

### Added
- ⌨️ 键盘快捷键：`A`/`B`/`C`/`D` 选择，`Enter` 提交，`←`/`→` 切换题目
- ⏱️ 番茄钟专注计时（25 分钟）
- ✨ 背诵模式：直接显示答案与解析，适合考前速览
- 📕 错题复盘本：列表 + 抽卡两种复习方式，自动收集做错的题
- 🔖 题目收藏
- 全局 `:focus-visible` 焦点环，配合键盘操作
- 卡片入场动画与列表错峰出现，并遵循 `prefers-reduced-motion`
- 错题本空状态与「去刷题」CTA；为空时隐藏列表/抽卡切换
